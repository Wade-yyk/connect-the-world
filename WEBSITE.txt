SYDE 671 Assignment 3 - presentation website

Double-click open_website.cmd to start http://127.0.0.1:8765/ and open it.
Keep the console window open while previewing; close it to stop the server.
Alternatively, open index.html directly in a browser (not a file-preview panel).
The website works offline without an installation or build step.

Updating calculations
  1. Edit point annotations using mark_points.py.
  2. Run python a2_recover_homographies.py (or run_a2.cmd).
  3. Refresh index.html. A.2 also refreshes assets/results.js automatically.
  To refresh the page after editing templates/index.html: python build_showcase.py.
  To regenerate A.3: python a3_rectify.py (or run_a3.cmd).
  Edit correspondences/rectification/points.json to change the selected corners.
  Or double-click open_a3_point_picker.cmd, choose four corners in two different photos,
  save each example, then click the generate/update button.
  To regenerate A.4: python a4_mosaics.py (or run_a4.cmd).
  A.4 reads the A.2 point files directly; regenerate it after changing those points.
  To regenerate B.1: python b1_detect_corners.py (or run_b1.cmd).
  Optional: --count 500 --threshold-rel 0.005. Coordinates use original pixels.
  To regenerate B.2: python b2_extract_descriptors.py (or run_b2.cmd).
  B.2 reads the saved B.1 ANMS points; rerun B.2 after regenerating B.1.
  To regenerate B.3: python b3_match_features.py (or run_b3.cmd).
  Optional: --ratio 0.7 --preview-limit 40. B.3 reads B.2 descriptors directly.
  The Euclidean distance ratio 0.7 corresponds to squared-distance ratio 0.49.
  To regenerate B.4: python b4_autostitch.py (or run_b4.cmd).
  Optional: --threshold-px 3 --max-trials 5000 --seed 671.
  B.4 reads B.3 matches and compares against the saved A.4 Laplacian mosaics.
  Regenerate stages in order after changing upstream photos, points, or settings.

Static hosting
  The repository root is the site root. index.html, assets/, photos/, and
  output/ must remain together. No external fonts, CDNs, or APIs are used.
  The source is compatible with repository-root static hosting such as
  GitHub Pages; hosting has not been configured or published by this change.
